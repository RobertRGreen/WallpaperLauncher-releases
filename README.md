# Wallpaper Launcher - releases

Downloads for **Wallpaper Launcher**, a desktop-style game launcher for Windows that sits on top of your wallpaper
(including Wallpaper Engine). Source code is private; this repo only hosts built releases.

## Install

1. Open the [latest release](../../releases) and download **WallpaperLauncher.exe**.
2. Double-click it and accept the install prompt (installs for your account only; no admin rights).
3. Windows SmartScreen may say "unknown publisher" because the app isn't code-signed yet: *More info > Run anyway*.

Requires Windows 10 (1809) or Windows 11, 64-bit. Nothing else to install.

## Trial and license

Free for 7 days, then the launcher locks until you enter a license key in **Settings > License**.

## Updates

The app updates itself: **Settings > Updates**. Releases marked *Pre-release* are the beta channel; the rest are stable.

## Uninstall

Windows Settings > Apps > Wallpaper Launcher.
